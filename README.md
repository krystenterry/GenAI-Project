# 🎯 AI Certification Study Buddy  

An AI-powered study assistant that generates **comprehensive open-book exam study guides** for certifications and topics of your choice. Built with **OpenAI**, **Python**, and **Streamlit**, this app produces structured study guides and downloadable PDFs to make learning efficient and exam-focused.  

---

## 🌟 Features
- Generate **all core exam concepts** for open-book tests  
- High-yield topics and common tricky areas highlighted  
- Certification-style **practice questions** included  
- Downloadable **PDF study guide** for offline studying  
- **Two study modes**:
  1. Learn Mode — simple explanation with analogies and key points  
  2. Exam Prep Mode — full structured concept map  

---

## 🛠 Tech Stack
- **Python** — app logic  
- **Streamlit** — interactive web app  
- **OpenAI API** — AI-generated study guides  
- **ReportLab** — PDF generation  
- **python-dotenv** — local API key management  

---

## 📝 Story / Project Journey
This project originally began as an **AI Note Generator**, designed to summarize study notes and provide quick explanations. After **countless code challenges**, especially while trying to securely manage the OpenAI API key, I decided to pivot.  

That struggle led to the creation of the **AI Certification Study Buddy** — a more robust, professional, and practical tool that not only survived all the hurdles but now **works flawlessly and produces downloadable PDFs**.  

It’s a testament to perseverance: sometimes deleting a project isn’t failure — it’s clearing the way for a stronger solution. 💪
